# 模型调用名称

控制台「模型与调试」按服务分组，支持折叠、全部展开/收起及搜索。
搜索时自动展开匹配组；清除搜索恢复原折叠偏好。偏好保存在本机浏览器，不含凭证。

显示名称、调用名称及内部路由独立：

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| 显示名称 | Qwen4-Max | 官方名称与页面展示 |
| 调用名称 | qoder-qwen4-max | SDK 的 model、三个推理协议及 /v1/models |
| 原始地址 | 服务ID/qmodel_latest | 适配器路由、白名单与请求记录 |

调用名称存于 SQLite。首次分配根据渠道和官方显示名生成；
冲突添加数字后缀。已有名称不随服务名、显示名或目录顺序变化。
自定义网关默认使用服务名称作为前缀；无法转换的中文前缀使用 `service`。

在模型「参数」中可以复制或编辑调用名称。
允许 1–96 位小写字母、数字、点、下划线和短横线，以字母或数字开头。
`auto` 系列为保留名称。不能覆盖另一模型已使用的名称或原始裸模型名。
保存新名称后，旧名称继续调用同一模型；响应的 model 使用当前主名称。
原始 `服务ID/模型ID` 地址仍可调用。`auto`、`auto:cost`、`auto:fast` 和 `auto:free` 行为保持原有含义。

```json
{
  "model": "qoder-qwen4-max",
  "messages": [{"role": "user", "content": "你好"}]
}
```

`GET /v1/models` 仅返回启用服务中可调用模型的主名称。
停用或从白名单移除后，主名称与历史名称都不能绕过限制。
删除服务保留名称记录，避免该名称自动转交给其他模型。
请求记录同时保存客户端请求值和实际内部地址，适用于核对路由及定位上游问题。

配置导出中的 `model_aliases` 包含主名称和历史名称。
导入按模型地址合并；名称冲突拒绝导入，不重新指向其他模型。
旧版本配置缺少该字段时，导入后自动补齐调用名称。

管理接口：

| 接口 | 作用 |
| --- | --- |
| GET /api/model-aliases | 读取全部主名称和历史名称 |
| PUT /api/model-aliases | 修改一个模型的主名称 |

编辑请求：

```json
{
  "backend_id": "内部服务ID",
  "model_id": "qmodel_latest",
  "alias": "daily-qwen",
  "previous_alias": "qoder-qwen4-max"
}
```

`previous_alias` 必须与当前主名称一致，避免不同窗口覆盖彼此的编辑。
